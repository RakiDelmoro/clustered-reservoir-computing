**ASSISTANT:** This is one of the most elegant architectural changes to explore. Here's why it aligns well with reservoir computing theory:

## The Intuition

| Neuron Type | Leaking Rate | Activation | Role |
|-------------|-------------|------------|------|
| **Fast** | α ∈ [0.2, 0.4] | **ReLU** | Nonlinear input encoding, dead/reborn on each timestep — quick transient response |
| **Medium** | α ∈ [0.5, 0.7] | **tanh** | Working memory with saturation — captures medium-term dynamics without unbounded growth |
| **Slow** | α ∈ [0.8, 1.0] | **tanh** | Stable long-term context — saturating activation prevents state explosion from slow integration |

The insight: **ReLU on fast neurons is safe** because high leaking rate means the state is mostly overwritten each timestep. **tanh on slow neurons is essential** because the state persists for many timesteps — ReLU accumulation could blow up.

The confusion matrix being **all zeros** (predicting one class for everything) is the smoking gun. Let me trace the information flow:

```
64×64 frame (4096D) → random projection → 128D → reservoir → 4000D features → ridge → 1 class
```

The 32:1 compression with a **frozen random matrix** is the problem. Here's why:

### The Random Projection Can't Distinguish Actions

Consider what differentiates the 4 action classes in the raw pixel space:

| Action | Key Signal in Pixels |
|--------|---------------------|
| Moving | Digit position shifts between frames |
| Spinning | Digit orientation changes (but generator line 162 says "simplified: no rotation for speed") |
| Collision | Two digits on canvas, overlap events |
| Stationary | Digit barely moves |

A random 4096→128 projection preserves **global dot products** on average (JL lemma), but:
- It doesn't preserve **position** — a digit at (10,10) vs (50,50) produces unrelated 128D vectors
- It doesn't preserve **velocity** — that requires comparing consecutive frames
- It doesn't preserve **count** — 1 digit vs 2 digits in different locations → similar 128D norms

The reservoir receives 128D vectors that are essentially **unrelated** across actions. No amount of reservoir dynamics can recover signal that was destroyed at the encoder.
